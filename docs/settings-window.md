# The settings window

Opens from the tray icon (or `hypr-screens settings`). On the left the pages, in sections; on the right the page you picked.

| Section | Page | What is there |
|---|---|---|
| System | **Screens** | every screen ever connected: rotation, scaling, resolution, place next to the laptop, one desktop – each on one row that folds out |
| | **Fixed screen** | which screen keeps one desktop, swap it, the desktop keys |
| | **Shortcuts** | the keys that hide and bring back windows |
| Devices | **Sound** | volume per device and app, Force Mute |
| | **Camera** | the turned virtual camera |
| | **Samsung** | charge limit, performance mode, device settings (only on a Galaxy Book) |
| Appearance | **Windows** | gaps, corners, border, blur, transparency, animations, see-through apps (Apply in the bar at the bottom) |
| | **Widgets** | the desktop widgets; each opens its own page, its colors a page under that one |
| | **General** | language, help, the full guide, the settings folder |

A page under another one has a back arrow in its title bar.

## Search

The field at the top of the sidebar – or just start typing anywhere, or Ctrl+F. It finds pages, sections and single settings by their names and by other words for them ("volume" finds Sound, "monitor" finds Screens). Each result shows where it is:

```
Widgets
Appearance
```

```
Weekday
Appearance → Widgets → Clock
```

Click a result (or Enter for the first one, ↑/↓ to choose) and the page opens, scrolls to the setting and marks it for a moment. A setting every widget has ("Accent color") comes once, as `Appearance → Widgets → …`. If a page fits, the rows that only mention it are left out – "widget" shows the Widgets page, not every switch called "Show this widget".

## Keys

| Key | Does |
|---|---|
| typing, Ctrl+F | search |
| Enter, ↑/↓ | open the first / choose a result |
| Esc | empty the search, then go back a page, then close the window |
